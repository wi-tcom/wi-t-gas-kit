# CHANGELOG — 見本：GAS の点検（gas-inspect）

版の番号は `main.js` の `GAS_INSPECT_VERSION`。

## 1.0.0（未公開）

- 最初の版。部品集 0.4.0 以降の部品（`version.js`・`handover.js`）を使う。
- 既存のプロジェクトに `wit-inspect.js` を 1 つ足し、`witInspect()` で点検する。
- 点検すること：トリガー（数・関数がない・重なり・シンプルトリガーと同じ名前）、トリガーで動く関数のロックと失敗の扱い、承認済みの権限（広いもの）、ウェブアプリ、タイムゾーン、WitGas の部品の版。
- 目で確かめること（点検結果に行として出す）：6 分の上限、`appsscript.json` の `oauthScopes`、動き終わったトリガー、後片付け（元に戻したか）。
- 結果は「点検結果」シート、版・トリガー・権限・プロパティ（値は伏せる）・シートの構成は「引き継ぎ書」シート。
- 設定シートと `migrate()` は持たない（README の「設定と版上げ」を参照）。
