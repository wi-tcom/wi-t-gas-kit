# CHANGELOG — 見本：CSV照合（csv-reconcile）

版の番号は `main.js` の `CSV_RECONCILE_VERSION`。スキーマの版（データの形の版）は `CSV_RECONCILE_STEPS` の最後の段の番号。

## 1.0.0（未公開）

- 版の約束に合わせた最初の版。部品集 0.3.0 の部品を使う。
- 先方ごとに変える値（シート名・呼び名・キー・比べる列・列の対応・数の列・日付の列・全角半角・通知先）を、`main.js` の `CSV_RECONCILE` から「設定」シート（`WitGas.settings`）に移した。
- スキーマの版 1：「設定」シートを用意する。
- メニューに「設定と表を用意する（版上げのときも）」「点検する」「引き継ぎ書を作る」を足した。
- 「点検する」は、通知先が見本のアドレスのままなら知らせる。
- 照合の動き・シートの形（会計・CSV貼り付け・照合結果・実行記録）は、前の形と同じ。
- **前の形（版番号なし）からの版上げ**：前の形は `main.js` の `CSV_RECONCILE` に設定を書いていた。コードを入れ替えると、その値は「設定」シートの既定の値になる。入れ替える前に `CSV_RECONCILE` の値（特に `notifyTo`）を控え、「設定と表を用意する」のあとに「設定」シートへ入れ直す（README の「版上げのしかた」）。

## 版番号なし（最初の形）

- プルリクエスト #3 で main に入った最初の形。設定は `main.js` の `CSV_RECONCILE` に書いていた。
