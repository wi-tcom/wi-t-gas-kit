# CHANGELOG — 見本：帳票 PDF の一括作成（pdf-batch）

版の番号は `main.js` の `PDF_BATCH_VERSION`。スキーマの版（データの形の版）は `PDF_BATCH_STEPS` の最後の段の番号。

## 1.0.0（未公開）

- 最初の版。部品集 0.2.0 以降の部品を使う。
- 「明細」の 1 行から 1 枚の「お見積書」を PDF にして、スクリプトが作ったフォルダに置く。作成記録で作成済みを飛ばす。
- 件数が多いときは区切って続きを動かす（`WitGas.resume`）。
- 先方ごとに変える値は「設定」シート（`WitGas.settings`）。
- スキーマの版 1：「設定」シートと「作成記録」シートを用意する。
- 段階：1（動く）〜3（変えられる）のうち、定時に自動で動かす部分を除くところまで（README の「段階」を参照）。
